Conecta tu hoja de cálculo privada de Google Sheets para tener respaldo automático, ilimitado y accesible desde cualquier lugar.

Pega aquí la URL proporcionada al implementar tu Google Apps Script como Web App (acceso: "Cualquiera").

📘 ¿Cómo crear el Google Apps Script en 2 minutos? (Clic aquí)

1. Crea una nueva hoja en sheets.new.

2. Ve a Extensiones > Apps Script, borra todo y pega este código:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var body = JSON.parse(e.postData.contents);
  if (body.action === "sync") {
    sheet.clear();
    sheet.appendRow(["HabitFlow Backup", new Date()]);
    sheet.appendRow([JSON.stringify(body.payload)]);
    return ContentService.createTextOutput(JSON.stringify({status: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var raw = sheet.getRange(2, 1).getValue();
  return ContentService.createTextOutput(raw)
    .setMimeType(ContentService.MimeType.JSON);
}

3. Haz clic en Implementar > Nueva implementación > tipo "Aplicación web".

4. En "Quién tiene acceso", selecciona Cualquier usuario y copia la URL terminada en /exec.
