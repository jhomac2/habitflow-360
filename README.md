# ⚡ HabitFlow 360 v4 — Control de Hábitos, Tareas por Carpetas, Pomodoro &amp; Onboarding

**HabitFlow 360 v4** es una aplicación web moderna, ultra-intuitiva y potente para la gestión personal de hábitos, tareas por carpetas madre, enfoque Pomodoro y seguimiento de rutina diaria.

---

## 🌟 Novedades Clave en la Versión v4

* **⏱️ Hábitos con Tiempo &amp; Elección de Pomodoro:** Al hacer clic en un hábito con minutos asignados (ej. *Estudiar Inglés - 60 min*), puedes elegir entre **Iniciar en Pomodoro** o **Marcar como Hecho Manualmente**.
* **✅ Cancelar o Completar Pomodoro al Instante:** Si entraste al Pomodoro por error o terminaste antes de tiempo, cuentas con los botones de **Marcar Hecho Ahora** o **Cancelar**.
* **💡 Guía Rápida de Inicio (Onboarding Tour):** Recorrido interactivo paso a paso para usuarios nuevos explicándoles dónde está cada sección.
* **📂 Tareas por Carpetas Madre:** Clasificación de pendientes por proyectos (*Universidad, Casa, Trabajo*).
* **🌌 Fondo Animado 3D (Three.js):** Constelación de partículas dinámicas y ligeras para móviles.
* **🎉 Animación de Confeti:** Celebración visual con efectos de dopamina al cumplir hábitos y tareas.

---

## 🚀 Instalación Rápida
1. Copia el contenido del archivo `codigo-habitflow-360-v4.txt` en un archivo llamado `index.html`.
2. Súbelo a **GitHub Pages** para tener tu propia app pública en vivo.
